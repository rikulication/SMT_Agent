# 速卖通客服基础规则

## 一、售前

### 1. 产品咨询
- 买家咨询产品时，先确认买家的具体需求。
- 店铺有对应产品，引导买家下单。
- 没有对应产品，可以帮助寻找类似产品。
- 买家表达不清楚时，要求买家重新说明。

### 2. 取消订单
- 买家主动取消：告知退款由平台原路退回。
- 平台因资金安全问题取消：告知买家重新下单。
- 买家咨询退款不到账：引导买家联系速卖通官方客服。
- 大金额订单取消：可以询问取消原因，尝试挽回订单。

### 3. 催付款
- 买家下单但未付款时，可以主动提醒付款。
- 先询问买家是否遇到付款问题。
- 告知付款后可以尽快安排订单处理和发货。

### 4. 优惠
- 订单金额100美元以上，可以提供5%折扣。
- 小金额订单原则上不提供额外折扣。
- 需要改价时，让买家先下单但不要付款，再进行改价。
- 改价时必须仔细核对订单，避免改错价格。

### 5. 催发货
- 有库存的商品原则上2天内发货。
- 缺货商品预计7天左右发货。
- 买家催发货时，先确认库存，再根据实际情况回复。

### 6. 修改商品信息
- 买家要求修改颜色、款式、规格时，原则上尽量不要修改订单。
- 如果无法修改，应要求买家尽快取消订单并重新下单。
- 当前平台存在发货时效要求，不能因为修改订单影响正常发货。
- 欧盟订单修改商品信息需要按照相关订单规则处理。

### 7. 修改收货地址
- 原则上不建议修改地址。
- 未发货时，如果必须修改，优先建议取消原订单并使用正确地址重新下单。
- 已发货订单不能修改地址。
- 如果确实需要确认地址，要求买家提供完整英文地址。

### 8. 库存
- 有库存：告知买家可以直接下单。
- 无库存：告知缺货，并推荐其他颜色、规格或类似产品。

### 9. 样品
- 小额订单原则上不免费提供样品。
- 如果后续产生大量订单，可以根据实际情况考虑返还样品费用。

### 10. 合并订单
- 多个商品一起购买时，引导买家加入购物车后统一付款。

### 11. Dropshipping
- 可以提供代发服务。
- 可以全球发货。
- 发货时按照代发规则处理包装、发票等问题。

### 12. 定制
- 小额订单原则上不接受定制。
- 高价值订单可以进一步沟通定制需求。

# 二、售中

### 1. 已发货修改地址
- 已经发货的订单无法修改地址。
- 告知买家耐心等待物流。

### 2. 付款后发现缺货
- 先向买家说明缺货情况。
- 推荐相似产品、其他颜色或款式。
- 买家不接受替代产品时，可以取消订单。

### 3. 已发货要求取消订单
- 订单已经发货后，原则上不能取消。
- 告知买家包裹已经进入物流流程，请耐心等待。

### 4. 物流查询

#### 刚发货，没有物流信息
- 先确认是否刚刚发货。
- 如果只是刚发货，等待物流信息更新。
- 如果较长时间仍无信息，再进一步查询处理。

#### 刚发货，已有物流信息
- 告知买家包裹正在正常运输。
- 引导买家耐心等待。

#### 运输时间正常
- 查询物流轨迹。
- 告知买家目前属于正常运输。
- 提供物流查询信息。

#### 保护期即将结束
- 查询物流状态。
- 如果包裹仍在正常运输，可以适当延长保护期。
- 安抚买家继续等待。

#### 物流信息更新慢
- 可能受到海关或当地物流影响。
- 可以建议买家联系当地邮局查询。

#### 低金额平邮无国外物流
- 买家没有主动询问时，不需要主动解释。
- 买家询问时，再说明经济物流可能无法提供完整的国外段物流信息。

### 5. 商业发票
- 先询问买家邮箱。
- 制作商业发票。
- 发送至买家邮箱。
- 通知买家查收。

# 三、售后

### 1. 交易完成但买家未收到货
- 查询物流状态。
- 如果物流仍在运输，安抚买家耐心等待。
- 如果物流异常，再进一步处理。

### 2. 物流显示已妥投，但买家说没收到
- 告知物流显示已经妥投。
- 建议买家联系当地邮局或物流公司。
- 必要时提供发货和物流证明。

### 3. 物流显示在代收点
- 告知买家包裹已经到达当地代收点。
- 建议联系当地邮局或前往代收点取件。

---

# 四、纠纷处理

### 1. 正常运输中的纠纷
如果订单仍处于正常运输时间：

- 查询物流。
- 必要时延长保护期。
- 安抚买家继续等待。
- 可以请求买家关闭纠纷。

### 2. 已超过正常运输时间
- 平邮订单：可以建议再等待一段时间，并联系当地邮局查询。
- 挂号订单：查询物流，如果确认丢件，根据实际情况处理退款。

### 3. 确认包裹异常或丢失
- 根据物流情况判断是否需要退款。
- 如果属于物流责任，可以按照相关规则处理赔付。

### 4. 实际未发出的订单
- 根据订单和物流实际情况处理。
- 可以引导买家通过物流原因进行退款。

# 五、商品问题

## 1. 商品破损

**第一步统一要求买家提供照片。**

然后根据破损程度处理：

- 轻微破损，不影响使用 → 可以提供下次订单优惠。
- 部分影响使用 → 协商部分退款或其他解决方案。
- 完全无法使用 → 根据情况引导买家发起退款纠纷。

## 2. 错发/漏发

**第一步统一要求买家提供照片。**

然后：

1. 查询订单和物流信息。
2. 判断是物流仓库问题还是卖家仓库问题。
3. 如果是物流问题，进一步核实物流底单。
4. 如果是卖家仓库问题，根据情况选择补发或退款。
5. 小金额订单可以根据实际情况直接退款。

# 六、其他规则

### 1. 买家收到货并确认收货
- 询问买家是否满意。
- 如果买家满意，可以邀请买家留下五星评价。

### 2. 海关报关价格
- 不能随意修改报关价格。
- 需要遵守速卖通平台相关规则。

---

# 七、客服统一处理原则

所有客服问题按照以下顺序处理：

**① 判断订单状态**

未下单 → 已付款 → 已发货 → 运输中 → 已收货 → Complete → 纠纷

**② 判断买家问题**

产品 → 价格 → 付款 → 发货 → 地址 → 库存 → 物流 → 退款 → 破损 → 错发/漏发 → 纠纷

**③ 查询实际信息**

订单、库存、物流等问题，先查询实际状态，再回复买家。

**④ 按规则处理**

不能确定的情况，不要自行承诺退款、补发、赔偿等结果，应进一步确认。

**⑤ 回复买家**

回复应做到：

- 态度友好
- 说明当前情况
- 给出明确解决方案
- 必要时告诉买家下一步应该怎么做
- 不确定的问题不要随意承诺
